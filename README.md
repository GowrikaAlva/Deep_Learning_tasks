# Deep Learning Models: CNN, RNN, GAN

This project implements three deep learning models using TensorFlow/Keras:

- CNN (Convolutional Neural Network) for image classification  
- RNN (Recurrent Neural Network, LSTM, GRU) for text classification  
- GAN (Generative Adversarial Network) for image generation  

## 📊 Results

- CNN (Fashion-MNIST):
  - Simple CNN: 89.2%
  - Transfer Learning: 89.5%

- RNN (IMDB Dataset):
  - RNN: 73.24%
  - LSTM: 85.80%
  - GRU: 85.54%

- GAN:
  - Successfully generates images with gradual improvement over epochs

## ⚙️ Tools Used

- Python  
- TensorFlow / Keras  
- NumPy  
- Matplotlib  

## ▶️ How to Run

1. Install dependencies:
   pip install tensorflow numpy matplotlib

2. Run the notebooks:
   - cnn_simple.ipynb  
   - cnn_transfer.ipynb  
   - rnn_text_classification.ipynb  
   - gan_fashion_mnist.ipynb
